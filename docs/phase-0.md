# 실제 데이터 연동 전 확인할 사항

현재 코드에는 실제 Threads 엔드포인트·필드·권한에 대한 가정을 넣지 않았습니다.
Meta의 최신 공식 문서와 실제 앱 승인 결과를 기준으로 아래 표를 채운 후 어댑터를 구현합니다.

| 항목 | 현재 상태 | 남길 근거 |
| --- | --- | --- |
| 키워드 검색, TOP/RECENT 이용 권한 | 미확인 | 앱 승인 권한, 공식 문서, 읽기 요청 결과 |
| 한국어 검색·페이지네이션·호출 한도 | 미확인 | 대표 검색 결과, 한도·오류 응답 |
| 타인 게시물 ID·본문·작성자·시각·URL·미디어 | 미확인 | 실제 응답의 가용 필드와 조건 |
| 좋아요·댓글·리포스트·인용 수 | 미확인 | 필드별 접근 범위, 수집 불가 사유 |
| 타인 댓글·조회 수·댓글 내 링크 | 미확인 | 허용 여부; 미제공이면 기능 제외 |
| 외부 트렌드 제공원 | 미선정 | 공식/허용된 경로, 이용 조건·비용·갱신 주기 |
| 저장·AI 분석 목적·보유 기간·삭제 | 미확인 | 적용 약관·앱 심사 조건과 처리 설계 |
| DB 외부 보관·복원·백업 | 미구현 | 선택 저장소, 복구 테스트, 접근 권한 |

수집기 계약:

- `TrendSource.discover(at)` → 출처가 포함된 `Trend` 목록
- `PostSource.search(trends, at)` → `Observation` 목록
- 시각은 시간대 포함, 관측 지표는 음이 아닌 정수 또는 `None`
- 미제공 반응 필드는 `unavailable_reasons`에 사유 기록
- 합성·실데이터는 별도 DB/보고서 경로로 분리
- 인증 정보는 환경의 안전한 비밀 설정에서 읽고 로그·URL·DB·보고서에 저장하지 않음

현재 데모에는 비밀 변수 요구사항이 없습니다. 실제 인증 변수명·대상 도메인은
선택한 API와 승인된 인증 경로가 확정된 뒤 설정합니다.
실제 데이터 없이 검색 권한이나 수집 품질이 검증되었다고 보고하지 않습니다.
