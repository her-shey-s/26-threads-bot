# 개발 현황 · 2026-10-13

## 현재 범위

짧은 한국어 텍스트 글 중 반응이 큰 글을 Markdown으로 저장하고, Codex가 새 글 초안을 작성합니다.
주제는 무관합니다. 사용자가 선택한 기본 경로는 **수집 JSON 파일 가져오기 + Codex 글쓰기**입니다.
한국어는 지역 대리지표이며 실제 한국 위치는 미확인입니다. 자동 발행은 후속 범위입니다.

추가 구현:

- `collect`: JSON 정규화, 최신 관측 중복 제거, 길이·언어·미디어·기간·지역·지표 필터
- 총 반응과 글자 수를 함께 반영한 실험용 순위, Markdown/JSON 저장, 제외 사유 집계
- `write`: Markdown 기반 Codex 작성 요청 및 Codex JSON 초안 검증·저장
- 길이·원문 완전 복사·참고 ID·링크·중복 검사, 편집상 예상 후킹 점수순 정렬
- 선택적 한국 Google Trends RSS + Apify 수집 및 AI Responses API 연결 코드

현재 검증: 기존 테스트 12개 + 신규 16개, 합성 파일 9개 → 조건 충족 3개 → Codex 예시 초안 3개.
실제 Threads 수집 품질과 서비스 요청 성공은 미검증입니다.
환경에는 외부 서비스 키가 없으며 서비스 도메인도 허용 목록에 없습니다.
선택한 파일+Codex 경로는 키 없이 실행할 수 있습니다. 매일 자동 스케줄은 켜지 않았습니다.
사용법: `docs/reference-workflow.md`.

## 완료한 초기 구조

- Python 패키지·CLI, 교체 가능한 트렌드/게시물 수집기 인터페이스
- 합성 후보 수집, ID 중복 제거, 인기·시간 보정 점수 산정
- 누락 지표의 NULL·사유 보관과 순위 제외
- SQLite 저장, JSON·CSV 보고서, 실행 성공·실패 이력
- 재실행 중복 방지, 관측 지표 이력, 실패 시 DB 결과 롤백
- GitHub Actions 테스트와 수동 데모 워크플로
- 실제 API 연동 확인 문서와 Codex 공통 작업 지침

기준 로컬 검증: 테스트 12개 통과, 데모 후보 25개 → 고유 24개 → 각 순위 10개.
실제 Threads 검색·권한과 GitHub Actions 원격 실행 성공은 이 결과에 포함되지 않습니다.

## 다음 작업 순서

1. 실제 내보내기 JSON을 받아 형식·한국어 검색 최신성·미디어/지표 가용성 검증
2. 실제 자료로 Markdown 레퍼런스와 Codex 초안을 만들어 품질 확인
3. 관측 자료로 랭킹 기준을 조정하고 필요하면 외부 수집 자동화 연결
4. SQLite 외부 영속 저장·복구·백업 검증
5. 일일 예약 실행, 재시도, 인증 만료·실행 누락 감지와 선택적 알림

현재 운영 스케줄과 실사용 인증 설정은 없습니다. 파일 경로에는 Meta 앱 준비가 필요하지 않습니다.
다음 작업에서도 저장소 문서를 기준으로 진행 상태를 갱신합니다.
