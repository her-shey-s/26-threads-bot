# 개발 현황

## 완료한 초기 구조

- Python 패키지·CLI, 교체 가능한 트렌드/게시물 수집기 인터페이스
- 합성 후보 수집, ID 중복 제거, 인기·시간 보정 점수 산정
- 누락 지표의 NULL·사유 보관과 순위 제외
- SQLite 저장, JSON·CSV 보고서, 실행 성공·실패 이력
- 재실행 중복 방지, 관측 지표 이력, 실패 시 DB 결과 롤백
- GitHub Actions 테스트와 수동 데모 워크플로
- 실제 API 연동 확인 문서와 Codex 공통 작업 지침

기준 로컬 검증: 테스트 32개 통과, 데모 후보 25개 → 고유 24개 → 각 순위 10개.
실제 Threads 검색·권한과 GitHub Actions 원격 실행 성공은 이 결과에 포함되지 않습니다.
