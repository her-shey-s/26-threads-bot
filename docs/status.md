# 개발 현황

## 완료한 초기 구조

- Python 패키지·CLI, 교체 가능한 트렌드/게시물 수집기 인터페이스
- 합성 후보 수집, ID 중복 제거, 인기·시간 보정 점수 산정
- 누락 지표의 NULL·사유 보관과 순위 제외
- SQLite 저장, JSON·CSV 보고서, 실행 성공·실패 이력
- 재실행 중복 방지, 관측 지표 이력, 실패 시 DB 결과 롤백
- GitHub Actions 테스트와 수동 데모 워크플로
- 실제 API 연동 확인 문서와 Codex 공통 작업 지침

기준 로컬 검증: 테스트 12개 통과, 데모 후보 25개 → 고유 24개 → 각 순위 10개.
실제 Threads 검색·권한과 GitHub Actions 원격 실행 성공은 이 결과에 포함되지 않습니다.

## 다음 작업 순서

1. Meta 개발자 앱 준비 후, 공식 검색 권한과 실제 제공 필드를 확인하고 `phase-0.md`에 근거 기록
2. 허용된 외부 트렌드 소스 선정과 Threads 검색 수집기 구현
3. 실데이터의 가용 지표에 맞춰 랭킹 기준 조정, 대표 검색·보고서 검증
4. SQLite 외부 영속 저장·복구·백업 검증
5. 일일 예약 실행, 재시도, 인증 만료·실행 누락 감지와 선택적 알림

현재 운영 스케줄과 실사용 인증 설정은 없으며, 앱 등록만으로 검색 권한이 확인된 것으로 취급하지 않습니다.
다음 작업에서도 저장소 문서를 기준으로 진행 상태를 갱신합니다.
